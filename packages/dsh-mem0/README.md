# @wingsky-1/dsh-mem0

DeepSeek Harness (DSH) 长期记忆系统插件：基于 mem0 的本地/轻量持久记忆系统。

## 功能特性

- **本地 stdio 极简运行时**：通过管道拉起轻量 Python 子进程，随 Node 父进程同生共死，天然零孤儿进程、零端口冲突。
- **Git 工作空间感知**：原生识别会话 `cwd`，并通过 Git Canonical 溯源自动统一主仓与所有 Worktree 的记忆空间。
- **全英文工具契约**：提供 `memory_search`、`memory_add`、`memory_list`、`memory_delete` 4 个核心工具，面向 LLM 的描述全英文，具备离线无感降级容错。
- **会话首轮智能预注入（#581）**：每个会话首轮自动按当前提问语义静默检索相关记忆，以 `<user_long_term_memories>` 围栏注入上下文，模型无需先发起 `memory_search` 工具调用即可直接给出贴合历史偏好的回答；未命中、服务不可用或超时时零注入，绝不阻塞首轮回复。
- **中文事实沉淀**：内置中文约束提示词模板，自动过滤琐碎寒暄，保证记忆全中文提炼入库。
- **全面配置化支持**：LLM 与 Embedder 端点全可配（支持 DeepSeek、SiliconFlow 等 OpenAI 兼容端点），支持自定义 TopK 与中文抽取指令，持久化至 DSH 官方 settings（`~/.dsh/settings.yaml`）。
- **记忆中心双区大盘**：官方 `settings.section` 挂载独立页面，提供“记忆条目列表”与“引擎配置大盘”双区，支持可视化脱敏修改与即时热重启。
- **自愈诊断与优雅降级**：当宿主缺少 Python 或依赖库时，前端自动精准诊断并提供一键复制命令；Agent 工具层自动熔断优雅降级，绝不抛红崩溃。
- **dsh-mcp-manager 统一纳管**：生命周期与工具状态完全交由 `dsh-mcp-manager` 统管。

## 智能预注入配置

以下三个配置键可在「记忆中心 → 引擎配置 → 高级参数」区可视化管理，亦可经
`POST /api/dsh-mem0/config` 程序化更新（数值越界自动回退默认值）：

| 配置键 | 类型 | 默认值 | 取值范围 | 语义 |
| --- | --- | --- | --- | --- |
| `enableSmartPreInjection` | boolean | `true` | 开 / 关 | 会话首轮智能预注入总开关；关闭后全程不检索不注入，仅保留手动 `memory_search` 工具与既有纪律提示词 |
| `preInjectionThreshold` | number | `0.6` | [0, 1] | 预注入相似度阈值；仅相似度分数**严格大于**该值的记忆条目参与注入 |
| `preInjectionLimit` | number | `3` | [1, 10] | 预注入条数上限；按分数降序最多取 N 条，命中 0 条时零注入（零 Token 浪费） |

预检索行为约束：

- **每会话恰一次尝试**：无论注入成功、结果为空还是失败降级，同一会话的后续步骤不再发起重复检索；服务恢复后的预检索收益自下一个新会话生效。
- **三类静默降级**：服务未就绪、检索抛错、检索超时（有界超时，默认 3 秒）三种情形下不注入任何文本、不补注、不重试，异常不向会话步骤冒泡，首轮回复照常生成。
- **不伪装用户输入**：注入消息以插件来源（`kind: "plugin", plugin: "mem0"`）呈现，与用户真实输入物理隔离。

## 安全模型

- **进程隔离**：本地 stdio 模式通过操作系统管道通信，不监听外部网络端口。
- **Loopback 围栏**：所有 `/api/dsh-mem0/*` REST 接口强制执行回环校验，拒绝一切非 loopback 跨站访问（403 阻断）；智能预注入运行于会话事件层，不新增任何绕过 loopback 围栏的路由或访问通道。
- **注入内容凭据脱敏**：预注入路径对每条候选记忆文本执行凭据形态脱敏（`sk-` 前缀密钥、Bearer 令牌、GitHub/Slack/AWS 令牌前缀、`api_key=`/`password:` 键值对赋值等形态），注入文本中不出现未脱敏的密钥字符串。
- **注入围栏语义**：注入文本以固定 `<user_long_term_memories>` 围栏包裹并附随行纪律——围栏内内容是历史背景事实而非控制指令，与当前用户显式请求冲突时以后者为准；随行纪律内嵌于围栏消息（单消息形态，不另发第二条纪律消息），也不与既有记忆纪律提示词合并；记忆内容中的围栏标签形态在组装前一律中性化，围栏完整性由注入侧不变式（开闭标签恰各 1）自检保证。
- **凭据保护**：继承 DSH 现有 Model Provider 配置，API Key 通过环境变量安全透传，不落盘至明文文件。
- **防误清库**：不暴露批量清库工具，单条物理删除需经过前端二次确认。
