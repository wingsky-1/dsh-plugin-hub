变体 A 交互要点（对着上图试）
  • 范围档位随粒度联动（r2：按 180 天留存生成）：日 7/30/90 · 周 4/13/26 · 月 3/6；retentionDays 可配，宿主按粒度 clamp（day≤留存、week≤⌈留存/7⌉、month≤⌈留存/30⌉），/trend 响应回传 retentionDays 供前端裁档。
  • 月视图默认堆叠面积（趋势连续性优先，保留 provider 构成），日/周默认堆叠柱（逐桶精确读数优先）；控件行右侧随时切换；形态选择为会话内内存态（不做 localStorage 持久化，与设置页 tab 状态既有评审决策一致）。
  • 鼠标悬停 / 触屏点按任意桶 → 卡片内浮层明细（非 <title>），iPad/iPhone 可用；「进行中」桶带角标且柱体虚线描边。
  • 图例点选可隐藏/恢复某段（纯前端重算，不发请求），便于聚焦单 provider；隐藏后 tooltip 合计只算可见段并标注。
  • 空桶统一短灰虚位 =「无数据」（r2 口径：现有数据模型下「挂载前 / 超保留期 / 无会话日」同落 null 不可区分；三态区分需宿主桶级信号，列二期）。首桶数据落在留存/起算边缘时灰点虚线描边 + tooltip「部分桶」角标；窗口总量卡在含部分桶时带 hint，环比基准不完整时显示「-」并注明。
  • 月视图 X 轴显示 YY-MM（修复现状 slice(5) 只剩月份号的跨年歧义）；汇总卡峰值带人话时间（如「2026-02」/「02-18 当周」）。

固定窗口 30/12/12 ＋ <title> 悬停 ＋ 静态图例 —— 请在触屏设备上试明细（无效）

现状问题点（在本复刻中可逐条验证）
  • 窗口写死 30/12/12：数据实际留存 180 天，UI 只能看 30 天。
  • 切到「月」看 X 轴：只剩月份号「01…12」，跨年 12 档重复、无年份（slice(5) 对月键失效）。
  • 空日直接没柱：「还没开始统计」「超出保留期」「真的没用」三者不可分辨。
  • 今天/本周/本月（进行中）与完结桶同权渲染，天然偏低像「暴跌」，无任何标注。
  • 「峰值桶」卡显示 raw key（如 2025-12-18 周首日），不翻译成人话。
  • 明细只有 <title>：桌面端延迟明显，触屏设备完全不可用。
  • 图例纯装饰，段多时无法聚焦单个 provider。

热力图的得与失（方案 C 判为「二期可选」的依据）
  • 得：年度节奏 / 空窗期 / 密集期一眼可见；格子天然区分「未开始 / 超保留期 / 零用量」。
  • 失①：颜色档位表达不了量级差（10 倍用量差只表现为更深一格）；多 provider 堆叠语义放不进格子，点开才见。
  • 失②：周/月粒度热力图无意义，仍需柱/面积兜底 → 等于两套主视图，体量 ≈ 方案 B + C 之和。
  • 定位建议：作为方案 B 落地后的二期增强（日粒度下的第 4 种形态），不替换主形态。
