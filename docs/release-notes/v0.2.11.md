# v0.2.11

## 中文

本版本把插件集适配到 DSH `0.2.2-rc.1`（Cordis `4.1.0`，需 Node `>=24.9`），5 个包统一发布为
`0.2.11`，并退役 `@wingsky-1/dsh-lan-proxy`。局域网入口迁移至 DSH 原生能力，差异见下文；退役的只是旧
代理插件；不承诺 alpha 或其他 DSH 版本。聚合包与独立包只能二选一安装，混装会让 `dsh web`
启动报 duplicate entry 错误。

### 主要变化

- mcp-manager：修复 DSH rc.1 下 `ws_mcp_call` 转发失败
  （[#1192](https://github.com/wingsky-1/dsh-plugin-hub/issues/1192)），并包含项目根冷启动发现
  （[#1173](https://github.com/wingsky-1/dsh-plugin-hub/pull/1173)）与会话发布期工具限制重入修复
  （[#1190](https://github.com/wingsky-1/dsh-plugin-hub/pull/1190)）。
- MCP 单次结果最多 10 张图片、每张最多 8 MiB，超限图片不写入附件存储。
- notifier 与 provider-usage 完成 rc.1 适配；verify-isolated 同步 rc.1 隔离验证 CLI 契约。

### 升级

`0.2.11` 发布后执行以下命令。先停止正在运行的 `dsh web`，并备份插件配置与会话数据。

```sh
npm i -g @deepseek-ai/dsh@0.2.2-rc.1
dsh --version

# 全家桶用户（推荐）
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.11
```

独立包用户需对每个已安装成员各执行一次，把最后一条中的包名换成该成员，例如：

```sh
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.11
```

全部更新或移除完成后重启 `dsh web`；其他 profile 将命令中的 `web` 替换成目标 profile。

版本化 home upgrade 链会追加 `0.2.10 → 0.2.11` 无损刻度步骤，持久化形态不变。

### 移除已退役的 LAN 代理

只有当初独立安装过 `@wingsky-1/dsh-lan-proxy` 才需要执行；聚合包用户由上面的更新自动处理。

```sh
dsh plugin --profile web remove @wingsky-1/dsh-lan-proxy
```

原生 LAN 与旧 proxy 不是等价替换，旧 settings、配置与证书材料也不会被自动删除；迁移步骤见
[LAN proxy 退役迁移](../migrations/dsh-lan-proxy.md)。已知限制：上游 batch 缺陷仍在跟踪；
8 MiB 附近的大帧 stdio transport 尚未完成端到端验证；Windows Desktop、真实模型及 provider
凭据流程尚未复测。

## English

This release adapts the plugin collection to DSH `0.2.2-rc.1` (Cordis `4.1.0`, Node `>=24.9`),
publishes the five maintained packages together as `0.2.11`, and retires
`@wingsky-1/dsh-lan-proxy`. LAN entry points move to native DSH capabilities; see below for the
differences. Only the old proxy plugin is retired, and alpha releases or other DSH versions remain
unsupported. Install either the aggregate or individual packages, not both — mixing them makes
`dsh web` fail at startup with a duplicate entry error.

### Main changes

- mcp-manager fixes `ws_mcp_call` forwarding failures under DSH rc.1
  ([#1192](https://github.com/wingsky-1/dsh-plugin-hub/issues/1192)) and also includes
  cold-start project-root discovery
  ([#1173](https://github.com/wingsky-1/dsh-plugin-hub/pull/1173)) and the session-publish
  tool-restriction reentry fix ([#1190](https://github.com/wingsky-1/dsh-plugin-hub/pull/1190)).
- MCP accepts at most 10 images per result and 8 MiB per image; images above either limit do
  not continue into attachment storage.
- notifier and provider-usage complete their rc.1 adaptation; verify-isolated follows the rc.1
  isolated verification CLI contract.

### Upgrade

Run these commands after `0.2.11` is published. First stop the running `dsh web` and back up
plugin configuration and session data.

```sh
npm i -g @deepseek-ai/dsh@0.2.2-rc.1
dsh --version

# aggregate users (recommended)
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.11
```

Individual-package users repeat the last command once for every installed member, replacing the
package name with that member, for example:

```sh
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.11
```

After all updates or removals are complete, restart `dsh web`; for another profile, replace `web`
in the commands with the target profile.

The versioned home upgrade chain appends a lossless `0.2.10 → 0.2.11` step; the persisted
shape is unchanged.

### Removing the retired LAN proxy

Only needed if you installed `@wingsky-1/dsh-lan-proxy` as an individual package; aggregate
users are handled by the update above.

```sh
dsh plugin --profile web remove @wingsky-1/dsh-lan-proxy
```

Native LAN is not an equivalent replacement, and old settings, configuration and certificate
material are not deleted automatically; see the
[LAN proxy migration guide](../migrations/dsh-lan-proxy.en.md). Known limit: the upstream
batch defect is still being tracked, and large-frame stdio transport near the 8 MiB boundary
has not completed end-to-end verification. Windows Desktop, real-model runs, and provider
credential flows have not been retested.
