## 中文

### 概述

v0.2.6 是 0.2 线的第六个补丁版本：7 个包同版发布（均为 0.2.6）。用户可见的变化共四处：`dsh-notifier` 设置页支持 dry-run 先测后存；`dsh-lan-proxy` 设置页可下发 CA 证书（含 iOS 安装配套）；`dsh-mcp-manager` 三处安全与可见性修复（#770 收尾、secret-flag 脱敏、提示词泄漏修复 #922）；其余为文档与测试工程。无破坏性变更。

### 破坏性变更与迁移

无。本版两条升级链（mcp-manager、notifier）均为 0.2.5→0.2.6 空步推进刻度：升级后首次启动自动把刻度推到 0.2.6，历史记录、服务器配置与频道配置逐字不动。

### 升级指南

**1. dsh 本体**：本版基线仍是 `0.1.5-rc.1`，已升过的跳过此步：

```sh
npm i -g @deepseek-ai/dsh@0.1.5-rc.1
dsh --version   # 应显示 0.1.5-rc.1
```

**2. 升级插件到 0.2.6**（升级后需**重启一次** `dsh web`，bundle 层只在启动时组合）：

```sh
# 全家桶升到 0.2.6
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.6

# 或逐个插件指定版本（示例，按需替换包名）
dsh plugin --profile web update @wingsky-1/dsh-notifier@0.2.6
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.6
```

> 未全局安装 `dsh` 时，将上述 `dsh plugin ...` 换成 `npx @deepseek-ai/dsh plugin ...` 即可。

### 新功能

- **[dsh-notifier]** dry-run 测眼前草稿（#912 PR-B，#927）：设置页改完频道先测后存——草稿只做内存校验与试投递，不落盘；掩码按 id 还原，跨类型残留掩码整体拒绝并给出重填提示
- **[dsh-lan-proxy]** 设置页下发 CA 证书（#911，#921）：新增只读 `GET /api/dsh-lan-proxy/ca-cert` 三态下发 + `tlsCaCertFile` 配置键与设置卡下载直链，配套 iOS 安装说明；旧 `lan-proxy/` 落点经 migrate 域迁入包命名空间；畸形请求一律 400，不再静默回落

### 修复

- **[dsh-mcp-manager]** 系统提示词 `mcp__` 工具声明泄漏修复（#922，#923）：连接翻转期 deny 名单改为注册表优先（批量直挂 + 逐名回退），装配侧对 `tools:sdk` 段做声明级擦除并计数告警，指导语改为过渡态指引
- **[dsh-mcp-manager]** #770 遗留收尾：目录项目优先、脱敏秘密源单点、展示与落盘凭据闭环、写边界环境策略门（#924）
- **[dsh-mcp-manager]** 摘要投影对 secret-flag 参数值脱敏（#926）
- **[dsh-notifier]** 对称化脏比较与状态回显收敛（#912 PR-A，#915）：收窄轮询预算，绞杀状态文本弱断言

### 维护与工程化

- **[dsh-notifier]** client-dom 三原子判据 65 用例（#769，#916）
- **[docs]** 发版步骤补 upgrade 链处理（#913）；按需加载表补被委派路由行（#918）；文档体系闭环缺口补齐（#919）

- **[test]** 全包单测与门禁登记随 #912 / #921 / #927 新增用例同步

## English

### Overview

v0.2.6 is the sixth patch release on the 0.2 line: all 7 packages ship together (all at 0.2.6). User-visible changes in four areas: `dsh-notifier` settings gain dry-run test-before-save; `dsh-lan-proxy` settings can serve the CA certificate (with iOS setup notes); three `dsh-mcp-manager` security and visibility fixes (#770 close-out, secret-flag redaction, prompt-leak fix #922); everything else is docs and test engineering. No breaking changes.

### Breaking Changes and Migration

None. Both upgrade chains in this release (mcp-manager, notifier) advance 0.2.5→0.2.6 as empty steps: the first start after upgrade moves the stamp to 0.2.6 automatically, with history, server, and channel configuration left byte-for-byte intact.

### Upgrade Guide

**1. dsh CLI**: the baseline is still `0.1.5-rc.1` — skip this step if an earlier release already brought you there:

```sh
npm i -g @deepseek-ai/dsh@0.1.5-rc.1
dsh --version   # should print 0.1.5-rc.1
```

**2. Upgrade plugins to 0.2.6** (restart `dsh web` once afterwards — the bundle layer composes only at startup):

```sh
# Bundle to 0.2.6
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.6

# Or pin per-plugin versions (examples — replace with the packages you use)
dsh plugin --profile web update @wingsky-1/dsh-notifier@0.2.6
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.6
```

> If `dsh` is not installed globally, replace `dsh plugin ...` with `npx @deepseek-ai/dsh plugin ...`.

### Features

- **[dsh-notifier]** Dry-run test-before-save for drafts (#912 PR-B, #927): test edited channels from settings before saving — drafts are validated and trial-delivered in memory only, never persisted; masks are restored by id, and cross-type residual masks reject the whole draft with a refill hint
- **[dsh-lan-proxy]** CA certificate serving from settings (#911, #921): new read-only `GET /api/dsh-lan-proxy/ca-cert` tri-state endpoint plus a `tlsCaCertFile` config key with a download link on the settings card, iOS setup notes included; legacy `lan-proxy/` paths migrate into the package namespace; malformed requests uniformly return 400 instead of silently falling back

### Bug Fixes

- **[dsh-mcp-manager]** System-prompt `mcp__` tool-declaration leak fixed (#922, #923): the deny list during connection churn is now registry-first (batched mount with per-name fallback), the assembler erases leaked declarations from the `tools:sdk` section with a counting alarm, and the guidance copy now describes the transient state
- **[dsh-mcp-manager]** #770 close-out: project-first catalog, single redaction source for secrets, display/persisted credential closure, write-boundary environment policy gate (#924)
- **[dsh-mcp-manager]** Secret-flag argument values redacted in the summary projection (#926)
- **[dsh-notifier]** Symmetrized dirty comparison with converging status echo (#912 PR-A, #915): narrowed polling budgets, weak status-text assertions culled

### Maintenance and Engineering

- **[dsh-notifier]** 65 client-dom tri-atomic assertions (#769, #916)
- **[docs]** Upgrade-chain handling added to the release procedure (#913); delegated-route row added to the on-demand loading table (#918); documentation-system closure gaps filled (#919)
- **[contract]** Host-contract derivation script skeleton (#802, #914)
- **[test]** Package suites and gate registries synced with the new cases from #912 / #921 / #927
