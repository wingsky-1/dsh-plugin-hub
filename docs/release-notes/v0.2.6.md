## 中文

### 升级要做什么

按顺序做，这次多一步迁移，跳过会丢配置：

1. 先备份：个人配置目录、设置文件、插件自己的数据目录，有备无患；
2. 把网页版 dsh 停掉；
3. 把电脑里的 dsh 升到 `0.1.7-rc.2`，装完用第二行确认版本号：

```sh
npm i -g @deepseek-ai/dsh@0.1.7-rc.2
dsh --version   # 应显示 0.1.7-rc.2
```

4. 做一次插件行迁移（这次插件在配置里的代号换了新名字，不迁旧配置会被跳过）。先查有没有，再动手——下面命令没输出就直接跳过这步：

```sh
grep -n "ui-dsh-" ~/.dsh/profiles/web/cordis.patch.yml
```

有输出才需要改，只涉及下面六个，文件里有哪个改哪个，没有的别加，其他插件的行一个字都别碰：

```
ui-dsh-lan-proxy → dsh-lan-proxy
ui-dsh-mcp-manager → dsh-mcp-manager
ui-dsh-notifier → dsh-notifier
ui-dsh-provider-usage → dsh-provider-usage
ui-dsh-worktree-sidebar → dsh-worktree-sidebar
ui-dsh-decision-gateway → dsh-decision-gateway（装了单独版网关的才有）
```

- 有仓库代码的跑脚本，先看一遍改什么，确认没问题再落盘（脚本改前会自动备份）：

```sh
pnpm migrate:plugin-rows
pnpm migrate:plugin-rows --apply
```

- 没仓库、纯装包的用户手动改：打开个人配置目录下各 profile 的 `cordis.patch.yml`，按上面只改 `id`，名字、配置、开关都不要碰，改前先备份这个文件；

5. 再升级插件：

```sh
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.6
```

6. 重启网页版 dsh；
7. 去插件管理页看一眼局域网和 MCP 的设置页，确认都在；
8. 以前设过免打扰起止时间的：第一次打开会自动搬到新的时间窗里，其他数据都不动；自己手改过时间的，去设置里确认一眼。

另外两件不用做的事：设置分区不用搬，上版已经是新名字了；也别把 `settings.yaml.imported` 拷回 `settings.yaml`，系统不会重新消费它，拷了也没用。

### 新功能

- **免打扰多时间段**：提醒插件支持配置多个免打扰时段，之前只能设一个起止时间；
- **局域网安全证书**：可以一键生成本机证书，并在设置页下发证书；没有证书时不下发；
- **用量统计**：四个用量页面和报告有调整；法定节假日全天按低谷时段统计；
- **安全修复**：补了提示词泄露的堵截、敏感参数展示时的遮盖、凭据清理；调用超时时间改为从配置里读，原来固定 55 秒；
- **界面调整**：提醒插件的设置卡和管理面板换了样式；关闭面板后光标回到原来的位置；测试按钮多了发送前预览；
- **适配新版本 dsh**：各插件适配新 dsh 的设置模型，设置项的名字固定下来了；代号迁移见“升级要做什么”第 4 步。
- **稳定性修复**：并发写文件改用唯一临时文件名；存储清理失败时的告警带上全量明细。
- **决策网关单独发布**：新插件单独发 0.2.6 版，不在全家桶里面，需要的单独装：

```sh
dsh plugin --profile web update @wingsky-1/dsh-decision-gateway@0.2.6
```

### 其他

还顺手做了些内部代码整理和测试补充，不影响使用。

## English

### How to upgrade

Follow in order — there is one extra migration step this time, skipping it drops settings:

1. Back up first: your profile directory, settings files, and plugin data directories;
2. Stop the dsh web page;
3. Upgrade the dsh tool on your computer to `0.1.7-rc.2`, then check the version:

```sh
npm i -g @deepseek-ai/dsh@0.1.7-rc.2
dsh --version   # expect 0.1.7-rc.2
```

4. Migrate plugin row identities (plugin ids changed names; old entries get skipped without this). Check first — no output means skip this step:

```sh
grep -n "ui-dsh-" ~/.dsh/profiles/web/cordis.patch.yml
```

Only these six are affected — rename the ones present in your file, do not add missing ones, and do not touch any other plugin's rows:

```
ui-dsh-lan-proxy → dsh-lan-proxy
ui-dsh-mcp-manager → dsh-mcp-manager
ui-dsh-notifier → dsh-notifier
ui-dsh-provider-usage → dsh-provider-usage
ui-dsh-worktree-sidebar → dsh-worktree-sidebar
ui-dsh-decision-gateway → dsh-decision-gateway (only if you installed the standalone gateway)
```

- With a repo checkout, preview first, then apply (the script backs up before writing):

```sh
pnpm migrate:plugin-rows
pnpm migrate:plugin-rows --apply
```

- Pure package users without a checkout, edit by hand: open each profile's `cordis.patch.yml`, rename only the `id` values as listed above; leave names, configs and switches alone, and back up the file first;

5. Then upgrade the plugins:

```sh
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.6
```

6. Restart the dsh web page;
7. Open the plugin manager and check the LAN and MCP settings pages are there;
8. If you set quiet hours before: the first start after upgrade moves the old hours into the new time slots automatically, everything else stays untouched; take a glance in settings if you hand-edited them before.

Two things you do NOT need to do: settings sections stay put (already under the new names since the last version); and do not copy `settings.yaml.imported` back over `settings.yaml` — it will not be consumed again.

### New features

- **Multi-slot do-not-disturb**: the notifier takes several quiet periods; only one start/end pair before;
- **LAN certificates**: one-click local certificate generation, issued from the settings page; nothing is issued without a certificate;
- **Usage stats**: four usage pages and reports changed; public holidays count as off-peak all day;
- **Security fixes**: prompt-leak blocking, masking of sensitive arguments where shown, credential cleanup; call timeouts now come from settings, previously fixed at 55 seconds;
- **UI changes**: restyled settings card and management panel; focus returns to its previous spot after closing a panel; the test button gained a preview-before-send step;
- **Adapted to the new dsh**: all plugins fit the new settings model and setting names are stable now; see step 4 under “How to upgrade” for the identity migration.
- **Stability fixes**: concurrent writes use unique temp file names; store-cleanup failure warnings carry full details.
- **Decision gateway, separate release**: the new plugin ships 0.2.6 on its own, outside the family pack; install it separately if needed:

```sh
dsh plugin --profile web update @wingsky-1/dsh-decision-gateway@0.2.6
```

### Misc

Some internal code tidying and extra tests. No effect on daily use.
