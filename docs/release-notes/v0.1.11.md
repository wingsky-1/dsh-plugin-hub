This is a hardening and compliance release: third-party license collection built into the publish pipeline, the notifier host entry split into focused modules, lan-proxy smoke hardened against late-async false greens, and the self-built type layer fully retired in favor of official `@deepseek-ai/*` types. Recommended for all users. / 本次发布以加固与合规为主：发布管线内置第三方 license 归集门禁、通知插件宿主入口按职责拆分、局域网代理 smoke 修复迟到异步假绿，并彻底退役自建类型层改用官方类型。建议所有用户升级。

### Features / 新功能

- [repo] 迁入项目级 agent 环境：`.dsh/skills/` 新增维护编排层（oss-pipeline / oss-triage / oss-steering / oss-report）与方法论层 skills，配套 `agents/` 角色规程与授权标签体系，issue 驱动的自治维护循环制度化。 / Project-level agent environment introduced: orchestration-layer skills (oss-pipeline / oss-triage / oss-steering / oss-report) and methodology skills under `.dsh/skills/`, with role playbooks under `agents/` and an authorization label system, institutionalizing the issue-driven autonomous maintenance loop.

### Bug Fixes / 修复

- [dsh-web-file-preview] 解析祖先路径凭证并圈定点击拦截作用域：修复第三方插件 DOM 已携带完整路径却被裸文件名嗅探抢先导致的预览 404。 / Ancestor-path evidence parsing with scoped click interception: fixed preview 404s where third-party plugin DOM carried full paths that were overridden by bare-filename sniffing.
- [dsh-lan-proxy] smoke 收尾改为显式 `allSettled`：消除固定两轮 `setImmediate` 对异步断言深度的巧合覆盖，迟到的失败断言不再造成 exit 0 假绿（已注入迟到失败用例自验非零退出）。 / Lan-proxy smoke now awaits an explicit `allSettled` of collected async cases instead of two fixed `setImmediate` turns, so late-settling failing assertions can no longer slip past `process.exit(0)` as a false green.

### Maintenance / 维护与工程化

- [scripts] **第三方 license 归集进发布物**：构建链新增 `collect-licenses` 步骤，被内联进产物的库 license 文本自动归集到各包 `lib/THIRD-PARTY-LICENSES`，`pack:check` 断言其存在且覆盖全部被内联库；文档同步明确「运行时依赖 = 构建期内联，需随包附第三方 license」。 / Third-party license collection wired into publishing: a new `collect-licenses` build step gathers license texts of all bundled libraries into each package's `lib/THIRD-PARTY-LICENSES`, asserted by `pack:check`; docs now state that runtime dependencies are inlined at build time and must ship their licenses.
- [dsh-notifier] 宿主入口按职责拆分（config / message / history / quiet-hours / server），最大源文件 1326 → 535 行；smoke 测试按功能重组为多文件，单测试文件 ≤400 行，断言数 265 → 271 不降，导出面零变更零行为差异。 / Notifier host entry split by responsibility (config / message / history / quiet-hours / server), largest source file 1326 → 535 lines; smoke tests reorganized per feature with files ≤400 lines, assertions up 265 → 271, export surface unchanged.
- [types] 删除自建类型层 `types/dsh.d.ts`，宿主端全量切换官方类型导出（pnpm-workspace catalog 锁版 `@deepseek-ai/*`，仅 import type）。 / Removed the self-built type layer `types/dsh.d.ts`; host code now imports types exclusively from the official `@deepseek-ai/*` packages (catalog-pinned, import-type only).
- [docs] 角色规程与 skill 参考文档交叉引用补全；lan-proxy README 安全模型节明确披露 health 元数据（含 configDir 绝对路径）经代理对局域网可见。 / Cross-references between agent playbooks and skill docs completed; lan-proxy README security-model section now discloses that health metadata (including the configDir absolute path) is visible through the proxy on the LAN.
