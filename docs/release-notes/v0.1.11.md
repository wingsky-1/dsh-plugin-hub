# v0.1.11 发布说明 / Release Notes

## 中文

本次发布体量显著：依赖现代化工程以成熟开源库（selfsigned / http-proxy / 官方 MCP SDK / mime）替换四套手搓子系统并构建期内联、自动归集 license；用量插件新增按提供商设置页与注入容错补强；局域网代理与通知插件完成专项修复与可达性改进。建议所有用户升级。

### 新功能

- [dsh-provider-usage] **设置页按提供商重构**：用量统计 tab 改为「提供商手电琴列表」，折叠态徽标显示启用中适配器，展开页内管理候选适配器；新路由 `POST /adapters/add`（loopback 围栏内，文件路径登记用户适配器并热注册），`/adapters/select` 支持 `adapterId: null` 清空启用项；注入容错补强——形状校验拒收畸形导出、执行超时护栏防死循环阻塞采样、面板展示每个用户适配器最近错误。交互收敛（#74）：适配器候选行独立开关（唯一互斥，停用仅影响用量取数）、新增 `POST /adapters/inspect` 检测预览路由（回显导出信息不注册）、`adapters/add` 入参简化为仅 `file`（身份以模块导出为准）、清单升级 `providers` 数组并兼容旧结构、附 .mjs 适配器开发指导文档。
- [dsh-web-file-preview] **预览 404 负路径 basename 兜底搜索**：聊天正文仅给出裸文件名且文件位于子目录时，先经 `git ls-files` 流式搜索（第二命中即早停），唯一命中且存在性校验通过继续预览；非 git 目录回退黑名单遍历（跳 dot 目录与 node_modules、不跟随 symlink、20000 触顶）；多同名一律维持 404 绝不猜测。
- [repo] **迁入项目级 agent 环境**：`.dsh/skills/` 维护编排层（oss-pipeline / oss-triage / oss-steering / oss-report）与方法论层 skills，配套 `agents/` 角色规程与授权标签体系；建立界面改动验证证据约定（隔离环境实测截图归档至包内 docs/archive 并在 issue/PR 双向引用）。

### 修复

- [dsh-provider-usage] **适配框架边界治理批**：`timeoutMs` 由死配置键变为全链路生效；非 opencode provider 的 v2 样本归独立 legacy 桶并按样本宽度生成列名，消除渲染错位；工厂与 store 双侧校验 cols/values 长度；总览按各 provider 实际启用映射拉取；schema 改只读语义；slots 注入独立 try/catch 并纳入卸载清理；writeAdapterState promise 链串行化防落盘乱序；清理死代码群与 res 遮蔽；rename 失败清理 .tmp 残留。
- [dsh-lan-proxy] **设置卡片反馈链路**：非法配置值报错指明字段与合法范围；加载以 effective 校准展示、保存改增量提交不再覆盖组合层值；卡片可见压缩协商状态；全部 label 与控件 htmlFor 关联并补 inputMode。
- [dsh-notifier] **PR #24 评审遗留四项**：尖括号包裹邮箱 `<user@host>` 正常脱敏且 DSN 占位符不被二次破坏；Windows AUMID 改 `DSH.dsh-notifier` 消除公共命名空间碰撞；taskTitle 接入脱敏链后才进通知模板与历史；40 位 commit SHA 被长串规则误伤记录为已知行为。
- [dsh-web-file-preview] 解析祖先路径凭证并圈定点击拦截作用域，修复第三方插件 DOM 已携带完整路径却被裸文件名嗅探抢先导致的预览 404。
- [dsh-lan-proxy] smoke 收尾改显式 allSettled：迟到失败的异步断言不再造成 exit 0 假绿。

### 维护与工程化

- **依赖现代化（决策 #47）**：[dsh-lan-proxy] 自签证书改用 `selfsigned`（消除宿主 openssl 硬依赖）、HTTP/WS 转发改用 `http-proxy`（Host 防火墙等安全围栏保留为转发前置）；[dsh-mcp-manager] 协议+传输层改用官方 `@modelcontextprotocol/sdk` 薄适配（supervisor 调用面零变更，stdio 端到端契约证据：连接协商/callTool/杀进程退避重连）；[dsh-web-file-preview] MIME 表改用 `mime` 库。全部经 esbuild 构建期内联，运行时 npm 依赖保持为空。
- [scripts] **第三方 license 归集门禁**：构建链自动收集被内联库 license 文本至各包 `lib/THIRD-PARTY-LICENSES`，`pack:check` 断言存在且全覆盖。
- [dsh-notifier] 宿主入口按职责拆分（config/message/history/quiet-hours/server，最大源文件 1326→535 行）、smoke 测试按功能重组（单文件 ≤400 行，断言 265→271）。
- [types] 删除自建类型层 `types/dsh.d.ts`，宿主端全量切换官方 `@deepseek-ai/*` 类型导出（catalog 锁版，仅 import type）。
- [docs] agent 规程交叉引用补全；lan-proxy 安全模型节披露 health 元数据经代理对局域网可见。

## English

A substantial hardening, modernization, and feature release: the dependency-modernization program replaces four hand-rolled subsystems with mature open-source libraries (selfsigned / http-proxy / official MCP SDK / mime) inlined at build time with automated license collection; provider-usage gains a per-provider settings page and hardened adapter injection; lan-proxy and notifier receive focused bug-fix and accessibility passes. Recommended for all users.

### Features

- [dsh-provider-usage] **Per-provider settings page**: the usage tab now renders a provider accordion (collapsed badge shows the active adapter; expanded pane manages candidate adapters); new `POST /adapters/add` route inside the loopback fence registers file-based user adapters with hot reload; `/adapters/select` accepts `adapterId: null` to clear a provider; injection hardening adds module-shape validation, execution timeout guards, and last-error display per user adapter. Interaction pass (#74): per-adapter exclusive switches (disabling only affects usage sampling), a new `POST /adapters/inspect` preview route (echoes export info without registering), `adapters/add` simplified to a single `file` parameter (identity taken from module exports), manifest upgraded to a `providers` array with legacy compatibility, and an `.mjs` adapter authoring guide.
- [dsh-web-file-preview] **Basename fallback on preview 404**: when chat text mentions a bare filename living in a subdirectory, the server streams `git ls-files` for it (early-exit on a second hit), serving the unique stat-verified match; non-git workspaces fall back to blacklist traversal (skipping dot dirs and node_modules, no symlink follow, 20000 cap); ambiguous names keep the original 404.
- [repo] **Project-level agent environment**: orchestration-layer skills (oss-pipeline / oss-triage / oss-steering / oss-report) plus methodology skills under `.dsh/skills/`, role playbooks under `agents/`, and an authorization label system; a verification-evidence convention requiring archived UI screenshots for interface changes.

### Bug Fixes

- [dsh-provider-usage] **Framework boundary hardening**: `timeoutMs` is now effective end-to-end; non-opencode v2 samples go to a dedicated legacy bucket sized by sample width; length validation on both factory and append; overview fetches per enabled provider; read-only schema rendering; isolated error handling for settings-slot injection with unmount cleanup; serialized state writes; dead code removal; tmp-file cleanup on rename failure.
- [dsh-lan-proxy] **Settings-card feedback pass**: field-level validation messages; effective-value calibration with incremental saves so composite-layer values are no longer silently overwritten; visible compression status; full label-input association with inputMode.
- [dsh-notifier] **Four review follow-ups**: bracketed emails `<user@host>` redacted via dual lookbehinds without breaking DSN placeholders; Windows AUMID renamed to `DSH.dsh-notifier`; session titles sanitized before entering notifications/history; commit-SHA false positives documented as known behavior.
- [dsh-web-file-preview] Ancestor-path evidence parsing with scoped click interception fixes preview 404s caused by bare-filename sniffing overriding full paths already present in third-party DOM.
- [dsh-lan-proxy] Smoke now awaits an explicit allSettled of collected async cases, so late-settling failing assertions can no longer produce exit-0 false greens.

### Maintenance

- **Dependency modernization (decision #47)**: [dsh-lan-proxy] selfsigned replaces the openssl subprocess; http-proxy takes over HTTP/WS forwarding behind unchanged security fences. [dsh-mcp-manager] protocol/transport layers become thin adapters over the official MCP SDK (zero supervisor-facing changes; stdio end-to-end contract evidence: negotiation / callTool / bounded-backoff reconnect). [dsh-web-file-preview] hand-written MIME table moves to the mime library. All build-time-inlined with empty runtime dependencies.
- [scripts] **Third-party license collection gate**: bundled libraries' license texts are gathered into each package's `lib/THIRD-PARTY-LICENSES`, asserted by pack:check.
- [dsh-notifier] Host entry split by responsibility (config/message/history/quiet-hours/server, largest source file 1326→535 lines); smoke tests reorganized per feature (files ≤400 lines, assertions 265→271).
- [types] Self-built type layer `types/dsh.d.ts` removed; host code imports types exclusively from official catalog-pinned `@deepseek-ai/*` packages (import-type only).
- [docs] Agent playbook cross-references completed; lan-proxy security model now discloses LAN-visible health metadata.
