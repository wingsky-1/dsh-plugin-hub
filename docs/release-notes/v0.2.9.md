## 中文

本版本包含自 v0.2.8 以来的通知、MCP 管理与用量面板修复，以及有限维护声明。DSH 适配基线仍为 0.2.0-rc.2；不承诺 alpha 适配。

### 维护节奏

项目进入有限维护阶段，维护者目前暂停使用 DSH。优先处理影响现有用户的明确缺陷、安全与数据问题；上游 rc 适配按影响和维护成本决定，不承诺逐版本跟进。新功能与全面重写暂缓，现有仓库、发布物及社区贡献继续保留。详见 [维护声明](https://github.com/wingsky-1/dsh-plugin-hub/issues/1121)。

### 用户可见的修复

- notifier：ntfy JSON 发布使用服务根地址、实际 topic 与数字 priority，兼容原有 topic URL 加默认模板的明确配置；保留自托管前缀，对冲突和歧义配置明确报错。[#1123](https://github.com/wingsky-1/dsh-plugin-hub/pull/1123)
- notifier：Windows 自定义音色路径改为编码数据传递，避免空格和脚本字符被当作 PowerShell 命令；播放失败可在宿主日志中检查；设置卡明确说明浏览器权限未授予时的标题/横幅降级（#1126 已合入）。[#1124](https://github.com/wingsky-1/dsh-plugin-hub/pull/1124)
- mcp-manager：切回前台时按请求工作区做非强制恢复，健康与在途连接保留；不同工作区互不吞掉恢复请求，同一工作区失败后可立即重试。已由 [#1127](https://github.com/wingsky-1/dsh-plugin-hub/pull/1127) 合入。
- notifier：修复凭据掩码合并、空值删除、配置写入并发、通知历史清空假成功和远程访问设置卡错误提示；重复频道身份保存时显式拒绝，避免静默覆盖凭据。会话标题按 Unicode 码点截断。[#1092](https://github.com/wingsky-1/dsh-plugin-hub/pull/1092)、[#1097](https://github.com/wingsky-1/dsh-plugin-hub/pull/1097)、[#1113](https://github.com/wingsky-1/dsh-plugin-hub/pull/1113)
- provider-usage：趋势页重做统计范围和对象选择，改善窄屏、键盘操作及图例；集中原子写入并补强失败清理测试。[#1096](https://github.com/wingsky-1/dsh-plugin-hub/pull/1096)、[#1113](https://github.com/wingsky-1/dsh-plugin-hub/pull/1113)
- 工程维护：统一五包 UI 原语，清理过期规则文档与重复实现，修正覆盖率、变异门禁口径（包括变异段台账的 scope/reuse 峰值口径）和 TLS 测试夹具检查；不降低门禁阈值。[#1089](https://github.com/wingsky-1/dsh-plugin-hub/pull/1089)

### 升级前阅读

1. 先备份 DSH_HOME 下相关插件配置与数据，再停止宿主并更新插件；安装聚合包或独立包时保持同一版本，重启后刷新浏览器页面。
2. notifier 的 0.2.8 → 0.2.9 配置迁移会删除未知键、非法类型或越界值，以及身份或类型无效的条目；缺少的内置频道及字段会补齐。合法显式值保留；重复 id 的条目不会在迁移中删除，需用户自行保留所需条目再保存。详见插件 README 的配置格式附录。
3. notifier 的 Bark / webhook 实际投递 URL 必须是可解析的 HTTP(S) URL，且不能包含 userinfo；请将 URL 中的凭据移到对应的已知凭据字段（如 Bark `deviceKey` 或 webhook `token`、`password`、`headerValue`）。DNS/IP 分类、逐跳重定向复检和连接 IP 钉定仅用于草稿 dry-run，不适用于保存后的真实投递。[#1092](https://github.com/wingsky-1/dsh-plugin-hub/pull/1092)
4. mcp-manager 默认禁止直接调用 `mcp__<id>__<tool>`，请把旧脚本或模型调用改为 `ws_mcp_call`，传服务器完整名称与裸工具名。[#1095](https://github.com/wingsky-1/dsh-plugin-hub/pull/1095)

### 验证边界

Windows 命令构造和失败结算有离线回归；尚无真实 PowerShell 5.1、声卡及听音验证。#1099 的统一可见性策略和扩展结果诊断未纳入本版；#1102 原始保存 400 输入尚未确认。MCP 恢复依据官方状态投影，不检测半开连接，必要时仍需显式重连；本版不宣称完整多用户 UI 隔离。

## English

This release includes notification, MCP management and usage dashboard fixes since v0.2.8, together with the limited-maintenance announcement. The DSH compatibility baseline remains 0.2.0-rc.2; alpha compatibility is not promised.

### Maintenance cadence

The project is entering limited maintenance, and the maintainer has temporarily stopped using DSH. Clear defects affecting existing users, security and data issues take priority. Support for upstream rc releases depends on impact and maintenance cost, without a promise to follow every release. New features and a full rewrite are paused; the repository, published packages and community contributions remain available. See the [announcement](https://github.com/wingsky-1/dsh-plugin-hub/issues/1121).

### Changes

- notifier now publishes ntfy JSON to the service root with a real topic and numeric priority, supports unambiguous legacy topic URLs and preserves self-hosted prefixes. Conflicting or ambiguous settings fail explicitly. [#1123](https://github.com/wingsky-1/dsh-plugin-hub/pull/1123)
- Windows custom sound paths are passed as encoded data instead of PowerShell source. Playback failures can be inspected in host logs; permission hints explain title/banner fallback when browser notifications are not authorized ([#1126](https://github.com/wingsky-1/dsh-plugin-hub/pull/1126)). [#1124](https://github.com/wingsky-1/dsh-plugin-hub/pull/1124)
- mcp-manager resumes the requested workspace without forcing healthy or pending connections to restart. Different workspaces do not suppress each other's requests, and a failed request can be retried immediately. Merged in [#1127](https://github.com/wingsky-1/dsh-plugin-hub/pull/1127).
- notifier fixes masked credential merging, empty-value deletion, concurrent settings writes, false success when clearing history and remote settings error feedback. Duplicate channel IDs are rejected on save instead of silently replacing credentials. Session titles are truncated by Unicode code point. [#1092](https://github.com/wingsky-1/dsh-plugin-hub/pull/1092), [#1097](https://github.com/wingsky-1/dsh-plugin-hub/pull/1097), [#1113](https://github.com/wingsky-1/dsh-plugin-hub/pull/1113)
- provider-usage improves trend scope and object selection, narrow layouts, keyboard interaction and legends; consolidates atomic writes with stronger cleanup tests. [#1096](https://github.com/wingsky-1/dsh-plugin-hub/pull/1096), [#1113](https://github.com/wingsky-1/dsh-plugin-hub/pull/1113)
- Maintenance work shares UI primitives across five packages, removes obsolete governance documents and duplicate code, and corrects coverage, mutation-gate (including mutation-segment ledger scope/reuse peak accounting) and TLS fixture checks without lowering gate thresholds. [#1089](https://github.com/wingsky-1/dsh-plugin-hub/pull/1089)

### Before upgrading

1. Back up relevant plugin configuration and data under DSH_HOME, stop the host, update the aggregate or individual packages consistently, restart and refresh browser pages.
2. The notifier 0.2.8 → 0.2.9 migration removes unknown keys, invalid types or out-of-range values, and entries with invalid identities or types. Missing built-in channels and fields are added. Valid explicit values remain; duplicate IDs are preserved during migration and must be resolved by the user before saving. See the configuration appendix in the plugin README.
3. notifier Bark / webhook delivery URLs must be parseable HTTP(S) URLs without userinfo. Move URL credentials into the corresponding known credential fields (such as Bark `deviceKey` or webhook `token`, `password` and `headerValue`). DNS/IP classification, per-hop redirect checks and connection IP pinning apply only to draft dry-runs, not saved real deliveries. [#1092](https://github.com/wingsky-1/dsh-plugin-hub/pull/1092)
4. mcp-manager denies direct `mcp__<id>__<tool>` calls by default. Migrate scripts or model calls to `ws_mcp_call` using the full server name and bare tool name. [#1095](https://github.com/wingsky-1/dsh-plugin-hub/pull/1095)

### Verification limits

Windows command construction and failure settlement have offline regression coverage; real PowerShell 5.1 execution, audio hardware and audible playback remain unverified. Unified visibility policy and expanded delivery diagnostics from #1099 are outside this release; the original settings-save 400 input from #1102 remains unknown. MCP recovery uses official status projections rather than half-open connection detection; explicit reconnection may still be needed. Full multi-user UI isolation is not claimed.
