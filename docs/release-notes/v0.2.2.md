## 中文

### 概述

v0.2.2 是 0.2 线的第二个补丁版本，主线为「**通知中心域化闭环 + provider-usage 用量趋势 + verify-isolated 加固**」。功能面：notifier 完成保存串行 guard、频道域保存与 409 冲突恢复、kinds 确认 CAS 闭环（#405 三批 PR），通知中心 UI/UX 现代化并新增 webhook 安卓推送频道（#508）；provider-usage 设置面板多 tab + 模型下拉 + 年报化（#537），会话用量「日/周/月」趋势与定时报告（#503）；verify-isolated 以 node 重写脚本并新增隔离审计白名单（B4）、verdict（B6）与证据目录外置（B7）（#538/#540），`--dsh` 版本锚定加固（#518）。修复面覆盖 notifier 置灰禁点与 DSH_HOME 落盘隔离、lan-proxy 下游断开传播上游、mcp-manager 结果投影与错误提示、verify-isolated 相对路径绝对化、codegraph 位置参数形态等。另有 shared/dsh-home 单一事实源重构收敛（#517）。

### 升级指南

**1. dsh 本体**：本版继续锚定 `dsh 0.1.2-rc.1`，无需升级；若当前 dsh 低于该版本请先升级：

```sh
npm i -g @deepseek-ai/dsh@0.1.2-rc.1
dsh --version   # 应显示 0.1.2-rc.1
```

**2. 升级插件到 0.2.2**（升级后需**重启一次** `dsh web`，bundle 层只在启动时组合）：

```sh
# 全家桶（聚合包 + 其拉齐的子包）升到 0.2.2
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.2

# 或逐个插件指定版本（示例，按需替换包名）
dsh plugin --profile web update @wingsky-1/dsh-notifier@0.2.2
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.2
```

> 未全局安装 `dsh` 时，将上述 `dsh plugin ...` 换成 `npx @deepseek-ai/dsh plugin ...` 即可。

## English

### Overview

v0.2.2 is the second patch release on the 0.2 line, centered on **notifier channel-domain closed loop + provider-usage usage trends + verify-isolated hardening**. Features: notifier lands serialized-save guard, per-domain baseline saving with 409 conflict recovery, and kinds-confirmation CAS closed loop (#405 PR1–PR3), plus a modernized notification-center UI/UX with a webhook channel for Android push (#508); provider-usage gains a multi-tab settings panel, model dropdown and yearly report (#537), and day/week/month usage trends with scheduled reports (#503); verify-isolated is rewritten in Node with audit whitelisting (B4), verdict output (B6) and external evidence dirs (B7) (#538/#540), and `--dsh` version anchoring (#518). Fixes cover notifier greyed-out disabled items and DSH_HOME-aware persistence, lan-proxy downstream-disconnect propagation, mcp-manager result projection and error hints, verify-isolated relative-path absolutization, and codegraph positional-argument handling. shared/dsh-home is also consolidated into a single source of truth (#517).

### Upgrade Guide

**1. dsh CLI**: this release keeps targeting `dsh 0.1.2-rc.1` — no upgrade is required. If your dsh is older, upgrade first:

```sh
npm i -g @deepseek-ai/dsh@0.1.2-rc.1
dsh --version   # should print 0.1.2-rc.1
```

**2. Upgrade plugins to 0.2.2** (restart `dsh web` once afterwards — the bundle layer composes only at startup):

```sh
# Bundle (aggregate + the sub-packages it pulls in) to 0.2.2
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.2

# Or pin per-plugin versions (examples — replace with the packages you use)
dsh plugin --profile web update @wingsky-1/dsh-notifier@0.2.2
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.2
```

> If `dsh` is not installed globally, replace `dsh plugin ...` with `npx @deepseek-ai/dsh plugin ...`.
