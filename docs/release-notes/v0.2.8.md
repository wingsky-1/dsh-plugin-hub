# dsh-plugin-hub v0.2.8 Release Notes

> **[中文](#user-content-zh)** · **[English](#user-content-en)**

> 这次要**先升 dsh 本体**到 `0.2.0-rc.2`，再升插件。顺序跟 v0.2.6 一样，颠倒或跳过会装不上。

> This release requires upgrading the dsh tool to `0.2.0-rc.2` **first**, then the plugins — same order as v0.2.6. Reversing or skipping it will not install cleanly.

## 中文

### 升级要做什么

1. 先备份：个人配置目录、设置文件、插件自己的数据目录；
2. 把网页版 dsh 停掉；
3. 把电脑里的 dsh 升到 `0.2.0-rc.2`，装完用第二行确认版本号：

```sh
npm i -g @deepseek-ai/dsh@0.2.0-rc.2
dsh --version   # 应显示 0.2.0-rc.2
```

4. 再升级插件：

```sh
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.8
```

5. 重启网页版 dsh；
6. 去插件管理页看一眼各插件的设置卡，确认都在。

不用做的事：插件在配置里的代号这次没变，不用跑插件行迁移脚本；设置项不用搬，存储数据也不用手工处理。

决策网关不在全家桶里，需要的话单独升：

```sh
dsh plugin --profile web update @wingsky-1/dsh-decision-gateway@0.2.8
```

### 修复

- **校准水位图不再被压扁或翻面**（#1086）：折线图的 y 轴下界原来对所有数据都钉在 0，但校准水位（余额减去累计充值）在消耗超过期初水位时天然为负；下界被抬到数据最低点之上，整段数据会被挤出画布，或者上下界直接倒置。现在按数据本身决定要不要留 0 地板。

### 适配

- **各插件适配 dsh `0.2.0-rc.2`**：宿主与客户端的类型面全面改用官方 `0.2.0-rc.2` 的类型派生。旧 runtime 不在本轮支持范围。

### 其他

- **三个包收窄了宿主入口的导出面**（mcp-manager 撤出 79 条、provider-usage 23 条、lan-proxy 17 条内部实现导出）：经 `dsh plugin` 正常安装使用不受影响；直接 `import` 宿主入口并依赖这些内部形状的调用方需要改用新的窄面。
- 门禁与工程侧收口，不影响使用：复杂度与变异覆盖率的豁免清理、共享层 TypeScript 化、CI 矩阵与门禁的 fail-closed 化等。

## English

### How to upgrade

1. Back up first: your profile directory, settings files, and plugin data directories;
2. Stop the dsh web page;
3. Upgrade the dsh tool on your computer to `0.2.0-rc.2`, then check the version:

```sh
npm i -g @deepseek-ai/dsh@0.2.0-rc.2
dsh --version   # expect 0.2.0-rc.2
```

4. Then upgrade the plugins:

```sh
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.8
```

5. Restart the dsh web page;
6. Open the plugin manager and check that every plugin's settings card is there.

Two things you do NOT need to do: plugin row identities did not change this time, so skip the plugin-row migration script; and settings sections stay where they are — no data needs manual handling.

The decision gateway is not part of the family pack — upgrade it separately if you use it:

```sh
dsh plugin --profile web update @wingsky-1/dsh-decision-gateway@0.2.8
```

### Fixes

- **The calibrated-balance chart is no longer squashed or flipped** (#1086): the y-axis lower bound used to be pinned to 0 for every dataset, but the calibrated level (balance minus cumulative top-ups) is legitimately negative once spending passes the opening level — so the bound was lifted above the lowest data point, pushing the whole line off the canvas or inverting the axis. The 0 floor is now applied only when the data itself warrants it.

### Adaptation

- **All plugins now fit dsh `0.2.0-rc.2`**: the host and client type surfaces are fully derived from the official `0.2.0-rc.2` types. Older runtimes are out of scope for this round.

### Misc

- **Three packages narrowed their host entry export surface** (79 internal exports withdrawn from mcp-manager, 23 from provider-usage, 17 from lan-proxy): normal `dsh plugin` installs are unaffected, but code that `import`s the host entry directly and relies on those internal shapes has to move to the new narrow surface.
- Gate and engineering cleanups with no effect on daily use: complexity and mutation-coverage exemption cleanup, the shared layer moved to TypeScript, fail-closed hardening in the CI matrix and gates.
