This release contains 1 critical bug fix and 3 other changes. It is strongly recommended to upgrade from 0.1.8.
本次发布包含 1 项重要修复与 3 项其他改动。**强烈建议从 0.1.8 升级到 0.1.9**（0.1.8 存在功能性缺陷）。

### Bug Fixes / 修复

- [dsh-notifier] **重要：修复 SSE 连接泄漏（0.1.8 回归）**——页面在后台/前台间切换重建连接时，旧 EventSource 连接未被关闭，长时间使用后逐步耗尽浏览器同源并发连接，导致所有请求长期停留在 pending 状态、通知与页面请求全部失效。现已将所有重建路径收敛到受控入口，先关闭旧连接再建立新连接，并记录关闭异常。 / **Important: fixed an SSE connection leak (0.1.8 regression)** — when the page reconnects after switching between background and foreground, the old EventSource connection was not closed; over time this exhausted the browser's same-origin connection pool, leaving every request stuck in a pending state and disabling notifications and page requests. All reconnect paths now go through a single guarded entry point that closes the old connection before opening a new one, and logs any close failure.
- [dsh-notifier] 系统通知原生二进制缺失/不可执行时仅记录日志、不再让通知功能崩溃（issue #1）。 / System notifications now only log an error instead of crashing the feature when the native binary is missing or non-executable (issue #1).

### Other Changes / 其他改动

- [dsh-notifier] 更正 macOS 系统通知说明，厘清双通道到达机器的方式（issue #1）。 / Corrected the macOS system-notification documentation and clarified how the dual channels reach the machine (issue #1).
- [docs] 新增统一 Issue Form 及其 config，覆盖全仓库插件的 bug 收集。 / Added a unified Issue Form with config for collecting bugs across all plugins in the repository.
- [release] 发布说明改为随每版入库、双语人工校订的 `docs/release-notes/<tag>.md`。 / Release notes are now curated bilingual files committed per version at `docs/release-notes/<tag>.md`.
