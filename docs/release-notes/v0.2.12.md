# v0.2.12

## 中文

本版本把插件集适配到 DSH `0.2.2-rc.3`（Cordis `4.1.0`，需 Node `>=24.9`），5 个包统一发布为
`0.2.12`。官方类型层 catalog（`pnpm-workspace.yaml`）与各包 peerDependencies 已锁步到
`0.2.2-rc.3`；不承诺 alpha、rc.1/rc.2 或其他 DSH 版本。聚合包与独立包只能二选一安装，混装会让
`dsh web` 启动报 duplicate entry 错误。

### 主要变化

- mcp-manager 将对外核心服务名从 `ctx.mcpManager` 改为 `ctx.wsMcpManager`，不提供旧名别名。
  兄弟插件需改用新服务名；官方或其他插件占用的 `ctx.mcpManager` 与本插件并存，互不覆盖。
- mcp-manager 修复服务重复提供问题
  （[#1196](https://github.com/wingsky-1/dsh-plugin-hub/issues/1196)）：重复 `apply` 复用已提供的
  `wsMcpManager`，不再重建 manager、路由、settings 或监听面。
- 非对话页回退到 `body` 布局时，mcp-manager 胶囊避让窗口控制按钮
  （[#1195](https://github.com/wingsky-1/dsh-plugin-hub/issues/1195)）；标题栏区域不可读或不相交时
  保持原位。
- 工具守卫与模型可见性只处理本插件 own 集合中的 server id。官方或兄弟插件直接注册的
  `mcp__<serverName>__<tool>` 保持可见；不要将同一个 MCP server 同时配置到官方入口和本插件
  `mcp.json`，否则会出现两边各自连接、工具语义重复的共存冲突。
- notifier 完成 rc.3 兼容：上游删除 `agents.isOwnedBy` 后，回退到 `ctx.subagents` 的树关系判断
  直接父会话，不抛 `TypeError`，也不丢失子任务完成通知。
- provider-usage 补齐 2027 年中国法定节假日表：2026 年 33 天加 2027 年 29 天，共 62 天；调休
  上班日不按节假日处理。
- verify-isolated 同步 rc.3 隔离验证基线，并保持临时 `DSH_HOME`、独立 profile、端口与清理契约。

### 升级

`0.2.12` 发布后执行以下命令。先停止正在运行的 `dsh web`，并备份插件配置与会话数据。

```sh
npm i -g @deepseek-ai/dsh@0.2.2-rc.3
dsh --version

# 全家桶用户（推荐）
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.12
```

独立包用户需对每个已安装成员各执行一次，把最后一条中的包名换成该成员，例如：

```sh
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.12
```

全部更新完成后重启 `dsh web`；其他 profile 将命令中的 `web` 替换成目标 profile。

版本化 home upgrade 链会追加 `0.2.11 → 0.2.12` 无损刻度步骤，持久化形态不变。mcp-manager 的
项目级多 root 配置仍按文件自带 `version` 字段 just-in-time 落定，不进入 home 级步骤表。

## English

This release adapts the plugin collection to DSH `0.2.2-rc.3` (Cordis `4.1.0`, Node `>=24.9`) and
publishes the five maintained packages together as `0.2.12`. The official type-layer catalog in
`pnpm-workspace.yaml` and every package peerDependencies lockstep to `0.2.2-rc.3`; alpha releases,
rc.1/rc.2 and other DSH versions remain unsupported. Install either the aggregate or individual
packages, not both; mixing them makes `dsh web` fail at startup with a duplicate entry error.

### Main changes

- mcp-manager renames its public core service from `ctx.mcpManager` to `ctx.wsMcpManager` and does
  not provide an alias for the old name. Sibling plugins must use the new service name; an official
  or third-party `ctx.mcpManager` can coexist without either side overwriting the other.
- mcp-manager fixes repeated service provisioning
  ([#1196](https://github.com/wingsky-1/dsh-plugin-hub/issues/1196)): a repeated `apply` reuses the
  existing `wsMcpManager` instead of rebuilding the manager, routes, settings or watchers.
- On non-conversation pages that fall back to `body` layout, the mcp-manager capsule avoids the
  window-control buttons ([#1195](https://github.com/wingsky-1/dsh-plugin-hub/issues/1195)); it
  keeps its original position when the titlebar area is unreadable or does not intersect.
- Tool guards and model visibility handle only server ids owned by this plugin. Tools registered
  directly by the official runtime or sibling plugins as `mcp__<serverName>__<tool>` remain
  visible. Do not configure the same MCP server in both the official entry point and this plugin's
  `mcp.json`; doing so creates two connections with overlapping tool semantics.
- notifier completes rc.3 compatibility: after upstream removed `agents.isOwnedBy`, it falls back
  to the `ctx.subagents` tree relationship to identify the direct parent session, avoiding a
  `TypeError` and preserving subagent completion notifications.
- provider-usage extends the Chinese public-holiday table through 2027: 33 days in 2026 plus 29
  days in 2027, 62 days total. Adjusted working weekends are not treated as holidays.
- verify-isolated follows the rc.3 isolated-verification baseline while retaining its temporary
  `DSH_HOME`, dedicated profile, port and cleanup contract.

### Upgrade

Run these commands after `0.2.12` is published. First stop the running `dsh web` and back up plugin
configuration and session data.

```sh
npm i -g @deepseek-ai/dsh@0.2.2-rc.3
dsh --version

# aggregate users (recommended)
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.12
```

Individual-package users repeat the last command once for every installed member, replacing the
package name with that member, for example:

```sh
dsh plugin --profile web update @wingsky-1/dsh-mcp-manager@0.2.12
```

After all updates are complete, restart `dsh web`; for another profile, replace `web` in the
commands with the target profile.

The versioned home upgrade chain appends a lossless `0.2.11 → 0.2.12` step; the persisted shape is
unchanged. mcp-manager project-level multi-root configuration still settles just in time according
to each file's own `version` field and stays outside the home-level step table.
