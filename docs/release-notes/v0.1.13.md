## 中文

本次发布以稳定性、安全与工程化为主线：dsh-mcp-manager 完成项目级 MCP 中间层路由重构（状态刷新收敛为变更点驱动）；dsh-provider-usage 内置 DeepSeek 官方用量适配器、修复一处 sanitizeHtml 实体编码绕过（安全洞）及一批取数 / 存储 / 子代理会话问题；dsh-notifier 消除两类误报；多个插件设置卡片视觉对齐官方规格；新增 dsh-subagent-model-inherit 插件，子 Agent 自动继承父会话的模型与思考等级。工程侧，Stryker 变异测试扩展至五个包并进入 PR 增量门禁。建议所有用户升级。

### 新功能

- [dsh-mcp-manager] **项目级 MCP 中间层路由 + 变更点驱动**（#234，Fixes #228 / #111）：模型面恒定两个工具 `ws_mcp_search` / `ws_mcp_call`，执行时按调用方会话当前 cwd 路由到对应工作空间连接池——不同工作空间注入不同 MCP、无命名冲突。每工作空间惰性连接 + 超时全套 + LRU 淘汰 + userDisabled 合并式持久化；有界指数退避重连（500ms 起 / 30s 上限 / 10 次停止后台重试）；目录 last-good 磁盘缓存 + 跨字段检索（含中文 substring 修复）与 unavailable 段；guard 层策略支持 allowTools / denyTools（deny 优先，全名或裸名键）；连接前探测同名 `mcp__` 工具与官方能力并存防双进程。状态刷新收敛为变更点驱动：setSession 零连接副作用、GET /servers 纯读、fs.watch 替代 mtime 轮询、emitStatus coalesce、SSE 标脏 + 客户端 invalidate 单飞。提供 `middleware: off/project/all` 双轨迁移，默认 `project`。
- [dsh-provider-usage] **内置 DeepSeek 官方用量适配器 + 胶囊峰谷时段倒计时**（#201）：守恒式推算逐函数移植自已验证的 user-file 原型（`GAP_MS=27h` 中断判定、TOL/ANOMALY 分层渲染、严格金额解析、本地时区日聚合等行为对齐）；内置适配器名 `deepseek-official-builtin`，避免与用户自装原型 `deepseek-official` 注册名冲突、两者可共存；胶囊面板新增峰谷时段倒计时徽标。
- [dsh-subagent-model-inherit] **新增插件：子 Agent 自动继承父会话模型与思考等级**（#153）：纯宿主端事件面实现——`agent/created` 三道门判定（origin 血缘 / 父存活 / 显式覆盖跳过）+ 父模型快照（取自父日志 request/header config），在子 scope 的 agent/request waterfall 首次注入 provider / model / reasoningEffort；经真实官方库 e2e 四场景实证与对抗评审（fallback 语义缺陷已修复为放行即真继承）。基建配套：plugins-manifest standalone 第三态、gate 脚本断言条件化（跟随客户端面/HTTP 面存在性）、gauntlet/observe/ci 登记新包（变异基线 96.00%）。demo 观察期独立发包，暂不进聚合包。
- [ci] **Stryker 增量模式接入**（#180）：夜间全量落基线缓存，PR 仅跑增量变异门禁；增量基线改为仓库内版本化文件（#205）。
- [scripts+ci] **CI path-filter 拆分 + repo-gate 聚合闸 + 夜间观察调度**（#175）：按变更路径过滤触发，聚合闸统一收口质量门禁结论。

### 修复

- [dsh-provider-usage] **sanitizeHtml 封闭 HTML 实体编码绕过（安全修复）**（#196，#105 子项③）：原实现为 11 组纯正则明文黑名单，`jav&#x61;script:` / `o&#110;click=` 等实体编码变体可完整穿透。现保留明文黑名单作为第一层，第二层对第一层输出做恰好一轮实体解码得到检测副本、在其上以 17 组 token 级模式定位危险载体、命中后仅从原文删除对应字节区间并迭代至不动点；具名实体表保守收编 44 键（大小写不敏感、分号可选）。安全不变量为结构性保证：输出恒为输入子序列（纯删除）。
- [dsh-provider-usage] **移除客户端 fetch 2s 硬超时**（#232，Fixes #231）：此前所有客户端请求被 2s 硬超时钳制且先于宿主端 5s abort 生效，远端 API 较慢时取数被误杀；现超时统一由宿主端控制，适配器开发引导补「超时控制位置」约束。
- [dsh-provider-usage] **warmup 改串行 await**（#176，Fixes #156）：多 provider 并发取数被全局 mutex busy 短路的问题。
- [dsh-provider-usage] **子代理会话 provider 检测沿 parentId 上溯并保持上次检测结果**（#188，Fixes #69）。
- [dsh-provider-usage] **历史存储卫生**（#209，#105②）：readDay 对 ENOENT 容错，prune 移出 append 热路径。
- [dsh-provider-usage] **输入健壮性加固**（#189，Fixes #184）：maxAgeDays 非正值回落默认值，readAdapterState 拒绝非对象输入；运行时 add 的适配器纳入热更新监视（#208，Fixes #206），适配器开发引导文档同步修订。
- [dsh-provider-usage] **refreshStats 取数前复检会话当前 provider**（#247，#71 A1）：宿主仅在切换会话 / roster 变化时发信号，会话内切模型/provider 无任何宿主信号，旧轮询只重拉旧 provider 数据、零自愈，胶囊长期滞留旧数据。现抽出 revalidateProvider 检测半区（detect 与取数共用）：60s 轮询、可见性恢复、手动刷新取数前均先复检当前会话实际 provider/model，变化即就地切换并重置渲染状态，切换后最长一个轮询周期内跟随；detect 未变分支立即补刷一次 stats——同 provider 会话间切换也即时刷新。
- [dsh-provider-usage] **热更新保持 enabled 语义并持久化，改名撞名保留旧条目并如实报错**（#244，#212）：registry 新增 replaceByFile 冲突预检先行——撞名或契约失败拒绝替换且旧条目原样保留，成功则逐 provider 精确恢复原启用关系；写盘改磁盘基线合并语义（保留显式 null 停用标记）；热更监视初始化移至 adapter-state 恢复之后，消除启动期初始同步写盘竞态。
- [dsh-web-file-preview] **md 预览内绝对路径 / 锚点链接 Modal 内原地处理**（#245，Fixes #45）：重写白名单外的链接此前既不重写也无兜底——绝对路径 md 引用点击整页导航离开 dsh web、纯锚点改 `location.hash` 扰动 SPA 路由、带 fragment 的文件引用锚点被丢弃。现绝对路径且可预览后缀与相对引用同路重写（Modal 内原地跳转 + 返回栈），不可重写链接一律 `target=_blank` + `noopener noreferrer` 兜底、绝不整页导航；纯锚点经 overlay 拦截默认 hash 导航、Modal 正文内平滑滚动 + 落点高亮（按 GFM slug 最小语义内联补齐 heading id，不引入新依赖）；`./f.md#g` fragment 经 openPreview 贯通，md 首次渲染后定位一次。
- [dsh-notifier] **fork 型委派子代理完成不再误报主任务 done**（#197）：判定补运行时归属；免打扰出错豁免修复——拦截不再消耗合并窗口，合并分支落 suppressed 历史（#155）。
- [dsh-notifier] **Windows toast 全面失效修复**（#252）：toast.ps1 无 UTF-8 BOM 且含中文注释，PowerShell 5.1 按 ANSI 码页解码致 ParserError 整脚本不执行——源文件补 BOM 且构建期强制校验/补写；`-Title=` 式等号单 token 在 PS 5.1 `-File` 下从不绑定，改标题/正文/silent 打包 base64(UTF-8 JSON) 经单一 `-Payload` token 传递；截断改码点边界防 emoji 代理对腰斩。
- [dsh-mcp-manager] **目录条目双缺省时剥离 text 字段**（#195）：恢复目录消息 JSON 可序列化。
- [dsh-mcp-manager] **修复 #234 中间层重构引入的浮窗状态回归**（#248）：summarize() 仅读 supervisors，项目级连接实际已连接、浮窗却恒显 stopped / 0 tools——现 middlewareMode 下从中间层连接池投影 {status,error}、tools 由目录缓存填充，/health 补 middleware 计数；顺带修 smoke 静态装载断链。
- [dsh-mcp-manager, dsh-lan-proxy, dsh-idle-archive] **设置卡片视觉对齐官方规格**（#221、#203）：精确对齐官方卡片规格，并去掉卡片自带 margin、间距交由官方容器 gap 统一（#224）。

## English

This release centers on stability, security, and engineering: dsh-mcp-manager completes its project-level MCP middleware routing refactor (with change-point-driven status refresh); dsh-provider-usage ships a built-in DeepSeek official usage adapter, fixes an HTML-entity sanitization bypass (security) plus a batch of sampling / storage / subagent-session issues; dsh-notifier eliminates two classes of false reports; settings cards across several plugins are visually aligned to the official spec; a new plugin, dsh-subagent-model-inherit, makes subagents automatically inherit the parent session's model and reasoning effort. On the engineering side, Stryker mutation testing now covers five packages and runs as a PR incremental gate. Recommended for all users.

### Features

- [dsh-mcp-manager] **Project-level MCP middleware routing + change-point-driven refresh** (#234, fixes #228 / #111): the model surface stays at two tools, `ws_mcp_search` / `ws_mcp_call`, routed at execution time to the connection pool of the workspace matching the calling session's cwd — different workspaces inject different MCP servers with no naming conflicts. Per-workspace lazy connections with full timeout handling, LRU eviction, and merged userDisabled persistence; bounded exponential-backoff reconnect (from 500ms, capped at 30s, background retries stop after 10 attempts); last-good on-disk catalog cache plus cross-field search (including a Chinese substring fix) and an unavailable section; guard-layer policy with allowTools / denyTools (deny wins, full-name or bare-name keys); pre-connect probing of same-named `mcp__` tools coexists with official capabilities and prevents double processes. Status refresh converges to change-point-driven: setSession has zero connection side effects, GET /servers is purely read-only, fs.watch replaces mtime polling, emitStatus coalesces, SSE marks dirty and clients invalidate with single-flight. Dual-track migration via `middleware: off/project/all`, defaulting to `project`.
- [dsh-provider-usage] **Built-in DeepSeek official usage adapter + peak/off-peak countdown badge** (#201): conservation-based estimation ported function-by-function from a verified user-file prototype (27h GAP interruption detection, TOL/ANOMALY tiered rendering, strict amount parsing, local-timezone daily aggregation all aligned); the built-in adapter name `deepseek-official-builtin` avoids clashing with a user-installed `deepseek-official` prototype so both can coexist; the capsule panel gains a peak/off-peak countdown badge.
- [dsh-subagent-model-inherit] **New plugin: subagents automatically inherit the parent session's model and reasoning effort** (#153): implemented purely on the host-side event surface — a three-gate check on `agent/created` (origin lineage / parent alive / explicit override skips) plus a parent-model snapshot (from the parent log's request/header config), injected once at the child scope's agent/request waterfall head as provider / model / reasoningEffort; verified with four e2e scenarios against the real official library and adversarial review (the fallback-semantics flaw was fixed to true inheritance upon admission). Infrastructure: plugins-manifest gains a standalone third state, gate-script assertions become conditional (following client-surface/HTTP-surface existence), and the new package is registered in gauntlet/observe/ci (mutation baseline 96.00%). Ships as its own package during an observation period; not yet in the aggregate bundle.
- [ci] **Stryker incremental mode** (#180): nightly full runs persist a baseline cache while PRs run only an incremental mutation gate; the incremental baseline becomes a versioned in-repo file (#205).
- [scripts+ci] **CI path-filter split + repo-gate aggregate gate + nightly observation schedule** (#175): triggers filter by changed paths, and a single aggregate gate collects quality-gate verdicts.

### Bug Fixes

- [dsh-provider-usage] **sanitizeHtml closed HTML entity-encoding bypass (security fix)** (#196, item ③ of #105): the previous implementation relied on 11 plain-text regex blacklists, fully penetrable by entity-encoded variants such as `jav&#x61;script:` / `o&#110;click=`. The plain-text blacklist stays as layer one; layer two decodes exactly one round of entities into a detection copy, locates dangerous payload patterns with 17 token-level patterns on the copy, deletes only the corresponding byte ranges from the original text, and iterates to a fixed point; the named-entity table conservatively admits 44 keys (case-insensitive, semicolon optional). The security invariant is structural: output is always a subsequence of the input (deletion only).
- [dsh-provider-usage] **Client-side fetch 2s hard timeout removed** (#232, fixes #231): all client requests were previously clamped by a 2s hard timeout that fired before the host's 5s abort, killing sampling against slower remote APIs; timeouts are now controlled solely by the host side, and the adapter guide gains a "where to put timeouts" constraint.
- [dsh-provider-usage] **Warmup switched to serial await** (#176, fixes #156): concurrent multi-provider sampling was being short-circuited by global mutex busy.
- [dsh-provider-usage] **Subagent-session provider detection walks up parentId and keeps the last result** (#188, fixes #69).
- [dsh-provider-usage] **History storage hygiene** (#209, item ② of #105): readDay tolerates ENOENT, and pruning moves off the append hot path.
- [dsh-provider-usage] **Input-robustness hardening** (#189, fixes #184): non-positive maxAgeDays falls back to the default and readAdapterState rejects non-object input; adapters added at runtime are included in hot-reload watching (#208, fixes #206), with the adapter guide revised accordingly.
- [dsh-provider-usage] **refreshStats re-checks the session's current provider before sampling** (#247, item A1 of #71): the host only signals on session switches / roster changes — switching models or providers within a session produces no signal at all, so the old 60s poll kept sampling the stale provider with zero self-healing and the capsule stuck on old data. A revalidateProvider detection half (shared by detect and the sampling path) is extracted: the 60s poll, visibility restore, and manual refresh all re-validate the session's actual provider/model before sampling, switching in place and resetting render state on change so the capsule follows within at most one polling cycle; when detect reports no change, stats are refreshed immediately once — so switching between sessions of the same provider also refreshes instantly.
- [dsh-provider-usage] **Hot reload preserves enabled semantics with persistence; rename collisions keep the old entry and report honestly** (#244, #212): registry gains replaceByFile with conflict pre-checks first — a name collision or contract failure rejects the replacement and keeps the old entry intact, while success restores each provider's original enabled relationship precisely; state writes switch to disk-baseline merge semantics (explicit null disable markers preserved); hot-reload watcher initialization moves after adapter-state restore, removing a startup synchronous-write race.
- [dsh-web-file-preview] **Absolute-path / anchor links in md preview handled in place within the Modal** (#245, fixes #45): links outside the rewrite whitelist previously had neither rewriting nor a click fallback — absolute-path md references navigated the whole page away from dsh web, pure anchors perturbed SPA routing via `location.hash`, and file-reference fragments were dropped. Absolute paths with previewable extensions now rewrite along the same path as relative references (in-place Modal navigation + back stack); non-rewritable links always fall back to `target=_blank` + `noopener noreferrer` and never navigate the whole page; pure anchors are intercepted by an overlay handler for smooth in-Modal scrolling with a brief highlight (heading ids supplied by a minimal inline GFM-slug implementation, no new dependency); `./f.md#g` fragments flow through openPreview and are resolved once after first render.
- [dsh-notifier] **Forked delegated-subagent completion no longer falsely reports the main task as done** (#197, ownership added to the completion check); do-not-disturb error-exemption fix — interception no longer consumes the merge window, and merged branches land in suppressed history (#155).
- [dsh-notifier] **Total Windows toast failure fixed** (#252): root-caused total Windows toast failure — a BOM-less ps1 with Chinese comments was ANSI-decoded by PS 5.1 into a ParserError, so the entire script never ran; a BOM is now added to the source file and enforced/patched at build time; `-Title=`-style equals-form single tokens never bind under PS 5.1 `-File`, so title/body/silent are packed as base64 UTF-8 JSON passed via a single `-Payload` token; truncation moved to codepoint boundaries to avoid splitting emoji surrogate pairs.
- [dsh-mcp-manager] **text field stripped when both directory-entry defaults are absent** (#195): directory messages become JSON-serializable again.
- [dsh-mcp-manager] **Floating-panel status regression introduced by the #234 middleware refactor fixed** (#248): summarize() read only supervisors, so project-level connections showed stopped / 0 tools despite being connected — under middlewareMode, {status,error} is now projected from the middleware connection pool with tools filled from the catalog cache, plus a middleware count in /health; a pre-existing smoke-suite loading gap is also fixed.
- [dsh-mcp-manager, dsh-lan-proxy, dsh-idle-archive] **Settings cards visually aligned to the official spec** (#221, #203): exact alignment with the official card spec, card-owned margins removed, spacing delegated to the official container gap (#224).
