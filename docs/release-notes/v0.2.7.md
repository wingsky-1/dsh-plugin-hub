## 中文

### 升级要做什么

这次不用升级 dsh 本体，也没有配置迁移要跑，按平时的方式升级插件就行：

1. 把网页版 dsh 停掉；
2. 升级插件：

```sh
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.7
```

3. 重启网页版 dsh。

设置项和已有数据都不用手工处理，升级过程不写用户数据。单独装的插件照旧按包名升到 0.2.7；决策网关不在全家桶里，需要的话单独装：

```sh
dsh plugin --profile web update @wingsky-1/dsh-decision-gateway@0.2.7
```

### 修复

- **MCP 管理器不再清空项目级会话绑定**（#1028）：官方会话快照还没就绪、或当前页签暂未被官方主视图持有时，本包以前按「没有项目」处理，向宿主发空的 `cwd`，结果是面板只剩全局条目、项目级导入报 `no active project session`。现在这种情况判定为「未知」，保持既有绑定不动，控制台打一次告警提示项目级 MCP 暂未绑定。
- **客户端不再自建会话镜像**：官方会话列表在 `0.1.7-rc.2` 起已经没有 `current` 字段，本包改为直接走官方会话服务，判据用官方的 `retainedBy.mainView`，不再维护一份自造的 `{current, byId}` 副本。

已知未解决、已写进 README 的限制：多个页签各自绑定不同会话时，宿主的 `projectRoot` 是单例，项目级 MCP 只能跟随其中一个页签；本包不自行仲裁哪个优先。

### 其他

内部工程改动，不影响使用：复杂度门禁一次性收紧到 10/15（存量告警清零）、等价性检查器入库、各包构建脚本形态断言、门禁自授权通道与空面豁免入口删除、补齐死代码判据。

## English

### How to upgrade

No dsh upgrade and no config migration this time — upgrade the plugins the usual way:

1. Stop the dsh web page;
2. Upgrade the plugins:

```sh
dsh plugin --profile web update @wingsky-1/dsh-plugins-all@0.2.7
```

3. Restart the dsh web page.

Settings and existing data need no manual handling; the upgrade writes nothing to your data. Standalone installs upgrade per package to 0.2.7 as usual. The decision gateway is not part of the family pack — install it separately if you want it:

```sh
dsh plugin --profile web update @wingsky-1/dsh-decision-gateway@0.2.7
```

### Fixes

- **The MCP manager no longer clears the project-level session binding** (#1028): before the official session snapshot was ready, or while a tab was not held by the official main view, the package treated it as "no project" and sent an empty `cwd` to the host, leaving the panel with global entries only and project-level imports failing with `no active project session`. Such a state is now treated as "unknown": the existing binding is kept, and the console logs one warning that project-level MCP is not bound yet.
- **The client no longer keeps its own session mirror**: the official session list has no `current` field as of `0.1.7-rc.2`, so the package now goes through the official session service and uses its `retainedBy.mainView` criterion instead of maintaining a self-built `{current, byId}` copy.

Known limitation, still open and documented in the README: with several tabs bound to different sessions, the host `projectRoot` is a singleton, so project-level MCP can follow only one of them; the package does not arbitrate which tab wins.

### Misc

Internal engineering changes with no effect on daily use: the complexity gate tightened to 10/15 in one step (backlog cleared), the equivalence checker landed, per-package build-script shape assertions, removal of gate self-authorization channels and the empty-face exemption entry, and additional dead-code criteria.
