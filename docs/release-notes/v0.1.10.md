### Features / 新功能

- [dsh-lan-proxy] **合并原独立插件 dsh-gzip 的 HTTP 响应 gzip 压缩能力**：经本插件访问时，对 `/api`（RPC）、`/plugins`（客户端 bundle）与静态资源等可压缩响应自动协商 gzip（SSE 流式响应豁免），会话历史等大 JSON 响应的远程访问速度显著提升。dsh-gzip 退役，安装 lan-proxy 即获得等价能力（npm 已对旧包标记 deprecated，见根 README「从旧包迁移」）。 / **Merged the HTTP response gzip compression of the retired standalone dsh-gzip plugin**: responses served through the proxy (RPC `/api`, client bundles `/plugins`, static assets) negotiate gzip automatically with SSE streaming exempted, greatly speeding up remote access to large JSON payloads such as session history. dsh-gzip is retired; installing lan-proxy provides the equivalent capability (the legacy package is deprecated on npm — see "Migrating from legacy packages" in the root README).
- [dsh-provider-usage] **重构为按 Provider 适配框架并更名**（原 `dsh-opencode-usage`）：内置 OpenCode Go 取数适配器，支持用户自定义宿主 JS 注入适配器，设置面板独立 tab，多 provider 用量悬浮框可扩展接入新数据源。配置不自动迁移，重装后请在面板重新确认（npm 已对旧包标记 deprecated）。 / **Rebuilt as a per-provider adapter framework and renamed** (from `dsh-opencode-usage`): ships a built-in OpenCode Go data adapter, supports custom host-side JS injected adapters, gains a dedicated settings-panel tab, and can be extended to new providers. Config does not migrate automatically — re-check your settings after reinstalling (the legacy package is deprecated on npm).
- [dsh-notifier] 脱敏规则表扩展；审批/提问通知路径接入会话标题；Windows toast AUMID 自举提升通知归属体验。 / Expanded sanitization rule table; approval/question notifications now carry session titles; Windows toast AUMID self-bootstrapping for better notification attribution.
