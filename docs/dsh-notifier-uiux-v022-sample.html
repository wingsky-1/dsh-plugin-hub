    本次改动点

  • 信息层级：双 tab 扩为三 tab——「通知事件 / 通知频道 / 通知记录」，历史独立成 tab；事件 tab 保留待确认 kind 徽标。
  • 控件现代化：checkbox → 开关（44×32 触控区 + aria-label）；路由由展开复选组改为频道 chips 直点切换，右侧状态标签动态显示「跟随默认 / 自定义 · N 频道」。
  • 路由语义定死：全亮 = 跟随默认（随频道启停动态）；任一 chip 点灭即物化为自定义快照；全灭 = 自动恢复跟随默认并 toast 反馈；虚线删除线 chip = 残留已删频道（保存时清理）。
  • webhook 频道（安卓）：预设 ntfy / Gotify / 自建 + Header 认证（token 不进 URL）+ JSON 模板编辑器；{{priority}} 为频道感知派生占位符（severity→ntfy priority 映射收口在服务端），文本占位符 JSON-aware 转义、{{ts}} 数字直出。
  • 保存栏：底部常驻「N 处未保存修改」脏状态 + 保存/放弃（diffSettingsPayload 已有能力）。

    • 对抗评审修订（r2）

  • 已修 P0×6：chips 默认语义与全灭歧义、mock 路由状态自相矛盾、{{severity}} 映射矛盾（改 {{priority}}）、模板 JSON 注入（声明 JSON-aware 渲染策略）、Gotify token 明文进 URL（改 Authorization 头）、switch 触控目标/无障碍名、webhook 卡头 390px 溢出（summary 换行 + 窄屏隐藏次要文本）。
  • 已砍（无数据支撑/炫技）：历史筛选 chips、记录级频道徽标、「未确认 kind」豁免徽标、「v0.2.2 新」版本徽标、webhook 卡强调色。
  • 可达性：chips 补 aria-pressed、移除残缺 role=tablist、小按钮/占位符 chips 触控提至 32px、tertiary 文本对比度上调（暗色值为 mock 自拟，落地依赖宿主变量）。

    • 已拍板（r3，全部落实进本样本）

  • ② 投递超时开放配置：1–60 秒，默认 10（UI min/max 限界 + 服务端 clamp）；超时与失败均落记录、不自动重试。
  • ③ 历史筛选 / 记录级「投递到哪些频道」徽标：需后端历史结构扩展，排期跟踪（后续在 #505 下拆 issue，本期不做）。

  • ⑤ 频道类型 SVG 图标保留。
